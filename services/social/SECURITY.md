# Security Policy

## Reporting a vulnerability

Use GitHub private vulnerability reporting for confidential security reports:

```text
https://github.com/Mochirii-Wushu/Mochirii-Website/security/advisories/new
```

Do not use public issues or pull requests. Include the affected route or
workflow, reproduction steps, impact, and whether member data or credentials
may be exposed. Do not include live secrets unless the security contact
requests a separately protected transfer.

Mochirii Social also publishes the canonical reporting metadata at:

```text
https://social.mochirii.com/.well-known/security.txt
```

The repository security policy is:

```text
https://github.com/Mochirii-Wushu/Mochirii-Website/security/policy
```

This policy does not promise a bounty or a fixed response time.

Only `https://social.mochirii.com` and the Social source in this repository are
in scope. Use accounts and data you own, keep requests minimal, and do not
perform denial-of-service testing, social engineering, phishing, spam,
credential attacks, destructive actions, persistence, malware delivery, bulk
collection, or testing against third-party provider systems. Stop immediately
if member data, credentials, another person's account, or service stability
could be affected, and send only the smallest redacted proof needed for review.
Allow time for investigation and remediation before public disclosure.
